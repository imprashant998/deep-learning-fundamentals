From Logits to Gradients: The Complete Story of Softmax, Cross-Entropy Loss, and Backpropagation

How does a neural network classifier turn its raw output numbers into probabilities, measure how wrong those probabilities are, and then compute the exact gradient that tells each logit how to change? A step-by-step visual walkthrough from logits through softmax, temperature scaling, cross-entropy loss, and the surprisingly elegant $q_i - y_i$ gradient identity.

Prerequisite: Part I — Information, Entropy & Cross-Entropy

In our previous set of notes, we built an understanding of information content, entropy, and cross-entropy from first principles—colored urns, surprise, and binary codes. We arrived at the formula $H(P, Q) = -\sum_i P_i \log Q_i$ and proved that it is minimized only when $Q = P$.

But in a real neural network, we don't directly output a probability distribution $Q$. Instead, the last layer computes a vector of raw, unconstrained numbers—called logits—and we need machinery to:

  1. Turn logits into a valid probability distribution (the softmax function),
  2. Measure how far that distribution is from the ground truth (the cross-entropy loss),
  3. Control the "sharpness" of predictions (the temperature parameter), and
  4. Compute the gradient of the loss with respect to each logit for backpropagation.

This second set of notes covers every one of those steps. By the end, the identity $\frac{\partial L}{\partial z_i} = q_i - y_i$ will feel less like a formula to memorize and more like the only natural conclusion of the mathematics.

Section 01

1. Logits: The Raw, Unconstrained Output of a Network

Consider a neural network that classifies images into $k$ classes. The very last linear layer computes:

$$z = W^{(L)} h^{(L-1)} + b^{(L)} \in \mathbb{R}^k$$

Here $h^{(L-1)}$ is the activations from the penultimate layer, and $W^{(L)}, b^{(L)}$ are the weights and biases of the final layer. Each component $z_i$ is a logit—a real number that can be positive, negative, or zero. There is no constraint forcing these numbers to sum to $1$ or be non-negative.

Why "Logit"? The name comes from the logistic function (sigmoid), where $\sigma(z) = \frac{1}{1+e^{-z}}$ maps a single real number $z$ to a probability in $(0,1)$. The inverse $z = \log\frac{p}{1-p}$ is called the log-odds or logit. In the multi-class case, softmax generalizes sigmoid, and the inputs to softmax inherit the name "logits." Think of logits as unnormalized log-probabilities: larger logit $\Rightarrow$ higher probability after softmax.

For a concrete example, suppose we have a 3-class classifier (cat, dog, bird) and the final layer produces:

$$z = [z_{\text{cat}},\, z_{\text{dog}},\, z_{\text{bird}}] = [2.0,\, 1.0,\, 0.1]$$

The cat logit is highest, suggesting the network "thinks" the image is most likely a cat. But $z_{\text{cat}} = 2.0$ is not a probability—it doesn't tell us how confident the network is in a meaningful way. We need to convert this vector into a proper distribution $q$ over the three classes.

Key Distinction: Logits vs. Probabilities
Logits $z$
  • • Any real number $z_i \in (-\infty, +\infty)$
  • • No constraint on sum
  • • Can be negative
  • • Raw network output
Probabilities $q$
  • • Each $q_i \in (0, 1)$
  • • Must sum to $1$: $\sum_i q_i = 1$
  • • Always non-negative
  • • Interpretable as confidence
Section 02

2. The Softmax Function: Turning Logits Into a Valid Probability Distribution

Given a vector of logits $z = [z_1, z_2, \dots, z_k]$, the softmax function maps it to a probability distribution $q = [q_1, q_2, \dots, q_k]$ via:

$$q_i = \text{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{k} e^{z_j}} \quad \text{for } i = 1, 2, \dots, k$$

Let's verify that softmax always produces a valid probability distribution:

  • Non-negativity ($q_i > 0$): Since $e^x > 0$ for any real $x$, every numerator $e^{z_i}$ is strictly positive, and the denominator $\sum_j e^{z_j}$ is also positive. So $q_i > 0$ always.
  • Summation to 1 ($\sum_i q_i = 1$): $\displaystyle \sum_{i=1}^{k} q_i = \sum_{i=1}^{k} \frac{e^{z_i}}{\sum_{j} e^{z_j}} = \frac{\sum_{i} e^{z_i}}{\sum_{j} e^{z_j}} = 1.$
  • Monotonicity: A larger logit $z_i$ produces a larger probability $q_i$ (because $e^x$ is strictly increasing).

Why Exponentials? The "Soft" Version of Argmax

The name "softmax" is revealing. Consider the hardmax (argmax) operation: it assigns probability 1 to the largest logit and 0 to everything else. Softmax is a smooth, differentiable approximation of this. As logits become very large in magnitude, softmax approaches hardmax:

Logits $z$ $e^{z_i}$ Softmax $q$ Behavior
$[1, 1, 1]$ $[e, e, e]$ $[0.333, 0.333, 0.333]$ Equal logits → uniform distribution
$[2, 1, 0]$ $[7.39, 2.72, 1.00]$ $[0.665, 0.245, 0.090]$ Spread logits → peaked distribution
$[10, 1, 0]$ $[22026, 2.72, 1.00]$ $[0.9999, 0.0001, 0.000]$ One dominant logit → near-hardmax

Worked Example: $z = [2, 1, 0.1]$

Let's compute softmax step by step for our cat/dog/bird classifier:

Step 1: Exponentiate each logit
$$e^{z_1} = e^{2.0} \approx 7.389, \quad e^{z_2} = e^{1.0} \approx 2.718, \quad e^{z_3} = e^{0.1} \approx 1.105$$
Step 2: Sum the exponentials
$$S = \sum_{j=1}^{3} e^{z_j} = 7.389 + 2.718 + 1.105 \approx 11.212$$
Step 3: Divide each by the sum
$$q = \left[\frac{7.389}{11.212},\, \frac{2.718}{11.212},\, \frac{1.105}{11.212}\right] \approx [0.659,\, 0.242,\, 0.099]$$

Verify: $0.659 + 0.242 + 0.099 = 1.000$ ✓. The network is about $66\%$ confident the image is a cat.

Section 03

3. The Log-Sum-Exp Trick: Numerical Stability and Shift Invariance

There is a serious numerical problem lurking in the naive softmax formula. Consider logits $z = [1000, 1001, 999]$. Computing $e^{1000}$ in floating-point arithmetic overflows to infinity on most hardware, even though the final probabilities should be perfectly well-defined.

Softmax Is Shift-Invariant

The key insight is that adding any constant $c$ to every logit does not change the softmax output. Let's prove it:

$$\frac{e^{z_i + c}}{\sum_{j} e^{z_j + c}} = \frac{e^c \cdot e^{z_i}}{e^c \cdot \sum_{j} e^{z_j}} = \frac{e^{z_i}}{\sum_{j} e^{z_j}} = q_i$$

The $e^c$ factors cancel in the numerator and denominator. This means $\text{softmax}(z + c) = \text{softmax}(z)$ for any scalar $c$. In particular, choosing $c = -\max(z)$ ensures that the largest exponent is $e^0 = 1$, preventing overflow:

$$q_i = \frac{e^{z_i - \max(z)}}{\sum_{j} e^{z_j - \max(z)}} \quad \text{(numerically stable softmax)}$$

Worked Example: Stable Computation for $z = [2, 0, 0]$

This is the example from the practice problems. True class is $y = 0$ (0-indexed).

Step 1: Shift for stability
$$\max(z) = 2, \quad z' = z - \max(z) = [0, -2, -2]$$
Step 2: Exponentiate the shifted logits
$$e^{z'} = [e^0, e^{-2}, e^{-2}] = [1, 0.13534, 0.13534]$$
Step 3: Sum
$$S = 1 + 0.13534 + 0.13534 = 1.27067$$
Step 4: Normalize
$$q = \left[\frac{1}{1.27067},\, \frac{0.13534}{1.27067},\, \frac{0.13534}{1.27067}\right] \approx [0.7870, 0.1065, 0.1065]$$
Why This Matters in Practice Every deep learning framework (PyTorch, TensorFlow, JAX) implements this shift internally. When you call torch.nn.functional.softmax(logits), it silently subtracts max(logits) first. You almost never need to worry about it, but knowing why helps you debug NaN losses when they appear.
Section 04

4. Temperature Scaling: Controlling the Sharpness of the Distribution

We can introduce a temperature parameter $T > 0$ that controls how peaked or flat the softmax output is:

$$q_i = \frac{e^{z_i / T}}{\sum_{j} e^{z_j / T}}$$

The name "temperature" is borrowed from statistical physics (the Boltzmann distribution). The analogy is exact:

  • $T \to 0^+$ (freezing): Dividing by a tiny $T$ magnifies the differences between logits. The largest logit dominates exponentially. The distribution approaches a one-hot vector (hardmax). The system "freezes" into a single state.
  • $T = 1$ (standard): Normal softmax—this is the default during training.
  • $T \to \infty$ (melting): Dividing by a huge $T$ shrinks all logits toward zero. All $e^{z_i/T} \to 1$, so the distribution approaches $[1/k, 1/k, \dots, 1/k]$ (uniform). Maximum entropy—maximum randomness.
Temperature $T$ Effective Logits $z/T$ Softmax Output $q$ Effect
$0.5$ $[4.0, 2.0, 0.2]$ $[0.870, 0.118, 0.012]$ Sharper — more confident
$1.0$ $[2.0, 1.0, 0.1]$ $[0.659, 0.242, 0.099]$ Standard softmax
$2.0$ $[1.0, 0.5, 0.05]$ $[0.443, 0.269, 0.288]$ Flatter — less confident
$10.0$ $[0.2, 0.1, 0.01]$ $[0.348, 0.333, 0.319]$ Nearly uniform

When Is Temperature Used?
  • • Training: Almost always $T = 1$ (standard softmax).
  • • Knowledge Distillation: Hinton et al. (2015) use $T > 1$ to soften teacher probabilities, revealing "dark knowledge" about inter-class similarities.
  • • LLM Sampling: In GPT-style generation, $T < 1$ makes output more deterministic (greedy), $T > 1$ makes it more creative (random).
  • • Calibration: Post-hoc temperature scaling tunes $T$ on a validation set to fix overconfident predictions.
Section 05

5. Cross-Entropy as the Loss Function: Connecting Information Theory to Neural Network Training

From our Part I notes, we know the cross-entropy between two distributions $y$ (true) and $q$ (predicted) is:

$$H(y, q) = -\sum_{i=1}^{k} y_i \log q_i$$

In classification, $y$ is a one-hot vector: if the true class is $c$, then $y_c = 1$ and $y_{j \neq c} = 0$. This collapses the sum to a single term:

$$L = H(y, q) = -\sum_{i=1}^{k} y_i \log q_i = -1 \cdot \log q_c - \sum_{j \neq c} 0 \cdot \log q_j = -\log q_c$$

The loss is simply the negative log-probability assigned to the true class. This has a beautifully intuitive interpretation:

  • If $q_c \to 1$ (perfect prediction): $L = -\log(1) = 0$. No loss — the model is fully confident and correct.
  • If $q_c \to 0$ (completely wrong): $L = -\log(0) \to +\infty$. Infinite penalty — the model assigned near-zero probability to the correct answer.
  • If $q_c = 0.5$ (uncertain): $L = -\log(0.5) \approx 0.693$ nats (or $1$ bit).

The KL Divergence Decomposition

Recall the fundamental identity:

$$H(y, q) = H(y) + D_{\text{KL}}(y \,\|\, q)$$

where $H(y) = -\sum_i y_i \log y_i$ is the entropy of the label distribution and $D_{\text{KL}}(y \| q) = \sum_i y_i \log \frac{y_i}{q_i}$ is the KL divergence from $q$ to $y$. For a one-hot label:

  • $H(y) = -1 \cdot \log 1 = 0$ (a certain event has zero entropy).
  • Therefore: $H(y, q) = 0 + D_{\text{KL}}(y \| q) = D_{\text{KL}}(y \| q)$.
Key Insight: Minimizing CE = Minimizing KL Divergence With one-hot labels, the entropy $H(y)$ is a constant (zero) that doesn't depend on the model. So minimizing the cross-entropy loss is exactly the same as minimizing the KL divergence $D_{\text{KL}}(y \| q)$—pushing the predicted distribution $q$ toward the true distribution $y$.

Why Not Mean Squared Error?

You might wonder: why not use $L_{\text{MSE}} = \sum_i (y_i - q_i)^2$ instead? There are several reasons:

Property Cross-Entropy $-\log q_c$ MSE $\sum(y_i - q_i)^2$
Gradient w.r.t. logits $q_i - y_i$ (simple!) Complex: involves $\frac{\partial q_i}{\partial z_j}$
Saturated logits ($q_c \approx 0$) Large gradient → strong signal Vanishing gradient → slow learning
Information-theoretic motivation Minimizes KL divergence $D_{\text{KL}}(y\|q)$ No clear probabilistic interpretation
Convexity w.r.t. logits Convex (unique minimum) Not convex w.r.t. logits

The first row is the most important: the gradient $q_i - y_i$ is the reason softmax + cross-entropy is the dominant combination in classification.

Section 06

6. Deriving $\frac{\partial L}{\partial z_i} = q_i - y_i$: The Elegant Gradient Identity

This is arguably the most important derivation in classification networks. We will compute $\frac{\partial L}{\partial z_i}$ where $L = -\log q_c$ and $q_i = \text{softmax}(z)_i$. We proceed via the chain rule:

$$\frac{\partial L}{\partial z_i} = \sum_{j=1}^{k} \frac{\partial L}{\partial q_j} \cdot \frac{\partial q_j}{\partial z_i}$$

Step 1: $\frac{\partial L}{\partial q_j}$

Since $L = -\log q_c$, the loss depends on $q$ only through $q_c$:

$$\frac{\partial L}{\partial q_j} = \begin{cases} -\dfrac{1}{q_c} & \text{if } j = c \\[8pt] 0 & \text{if } j \neq c \end{cases}$$

This simplifies our chain rule: only the $j = c$ term survives in the sum:

$$\frac{\partial L}{\partial z_i} = \frac{\partial L}{\partial q_c} \cdot \frac{\partial q_c}{\partial z_i} = -\frac{1}{q_c} \cdot \frac{\partial q_c}{\partial z_i}$$

Step 2: $\frac{\partial q_c}{\partial z_i}$ — The Softmax Jacobian

Recall $q_c = \frac{e^{z_c}}{S}$ where $S = \sum_j e^{z_j}$. We need two cases:

Case 1: $i = c$ (same class)

By the quotient rule:

$$\frac{\partial q_c}{\partial z_c} = \frac{e^{z_c} \cdot S - e^{z_c} \cdot e^{z_c}}{S^2} = \frac{e^{z_c}}{S} \cdot \frac{S - e^{z_c}}{S} = q_c(1 - q_c)$$
Case 2: $i \neq c$ (different class)

The numerator $e^{z_c}$ does not depend on $z_i$, only $S$ does:

$$\frac{\partial q_c}{\partial z_i} = \frac{0 \cdot S - e^{z_c} \cdot e^{z_i}}{S^2} = -\frac{e^{z_c}}{S} \cdot \frac{e^{z_i}}{S} = -q_c \cdot q_i$$

Compactly: $\frac{\partial q_c}{\partial z_i} = q_c(\delta_{ci} - q_i)$ where $\delta_{ci}$ is the Kronecker delta.

Step 3: Combine to get $\frac{\partial L}{\partial z_i}$

Case 1: $i = c$ (the true class)
$$\frac{\partial L}{\partial z_c} = -\frac{1}{q_c} \cdot q_c(1 - q_c) = -(1 - q_c) = q_c - 1$$

Since $y_c = 1$: $\frac{\partial L}{\partial z_c} = q_c - y_c$ ✓

Case 2: $i \neq c$ (any wrong class)
$$\frac{\partial L}{\partial z_i} = -\frac{1}{q_c} \cdot (-q_c \cdot q_i) = q_i$$

Since $y_i = 0$: $\frac{\partial L}{\partial z_i} = q_i - y_i = q_i - 0 = q_i$ ✓

Both cases unify into a single, stunningly elegant expression:

$$\boxed{\frac{\partial L}{\partial z_i} = q_i - y_i \quad \text{for all } i}$$
Why Is This Gradient So Beautiful?
  • • Simplicity: No division by $q_c$, no Jacobian matrices — just "predicted minus true."
  • • Sum-to-zero: $\sum_i (q_i - y_i) = \sum_i q_i - \sum_i y_i = 1 - 1 = 0$. This is a consequence of softmax shift-invariance: adding the same constant to all logits doesn't change the loss, so the gradient must be orthogonal to the all-ones vector.
  • • Self-correcting magnitudes: For the true class, $\partial L / \partial z_c = q_c - 1$ is negative (push the logit up). For wrong classes, $\partial L / \partial z_i = q_i$ is positive (push them down). The magnitude is proportional to the error.
  • • No vanishing gradients: Even when the model is badly wrong ($q_c \approx 0$), the gradient is approximately $-1$ — a strong learning signal. With MSE, the gradient would vanish due to the flat region of the softmax saturation.

Worked Example: $z = [2, 0, 0]$, True Class $y = 0$

From Section 3, we computed $q \approx [0.7870, 0.1065, 0.1065]$. The one-hot label is $y = [1, 0, 0]$.

Gradient
$$\frac{\partial L}{\partial z} = q - y = [0.7870 - 1,\; 0.1065 - 0,\; 0.1065 - 0] = [-0.2130,\; 0.1065,\; 0.1065]$$

Check: $(-0.2130) + 0.1065 + 0.1065 = 0.000$ ✓

Interpretation: The gradient says "push $z_0$ up by $0.213$ (make cat more confident), push $z_1$ and $z_2$ down by $0.107$ each (make dog and bird less confident)."

7. Where $\frac{\partial L}{\partial z}$ Fits in Backpropagation

The gradient $\frac{\partial L}{\partial z_i} = q_i - y_i$ is the starting point of backpropagation. It tells us how the loss changes with respect to the output of the last linear layer. From here, the chain rule propagates the gradient backward through the entire network:

Once we have $\frac{\partial L}{\partial z} = q - y$, backpropagation continues:

Gradient w.r.t. weights $W^{(L)}$
$$\frac{\partial L}{\partial W^{(L)}} = \frac{\partial L}{\partial z} \cdot (h^{(L-1)})^\top = (q - y) \cdot (h^{(L-1)})^\top$$
Gradient w.r.t. bias $b^{(L)}$
$$\frac{\partial L}{\partial b^{(L)}} = \frac{\partial L}{\partial z} = q - y$$
Gradient flowing to previous layer
$$\frac{\partial L}{\partial h^{(L-1)}} = (W^{(L)})^\top \cdot \frac{\partial L}{\partial z} = (W^{(L)})^\top (q - y)$$

This last quantity $\frac{\partial L}{\partial h^{(L-1)}}$ becomes the "incoming gradient" for layer $L-1$, and the recursion continues all the way to the first layer. The key point: everything starts from the simple $q - y$ vector.

Why Frameworks Fuse Softmax + CE Together In PyTorch, nn.CrossEntropyLoss takes raw logits (not softmax outputs) as input. It internally computes softmax and cross-entropy in a numerically fused way using the log-sum-exp trick, which is more stable than computing softmax and then taking the log separately. The gradient it backpropagates is exactly $q - y$. If you first apply softmax and then pass the result to nn.NLLLoss, you lose this numerical advantage.

Practice Problems

Practice 1 of 4

For logits $z = [0, 0, 0]$ (3 classes) and true class $y = 1$ (0-indexed), what is the cross-entropy loss $L = -\ln q_y$?

Hint: When all logits are equal, softmax produces a uniform distribution: $q_i = 1/k$ for all $i$. With 3 classes, $q_1 = 1/3$. Then $L = -\ln(1/3) = \ln(3)$.
Solution: All logits equal → $e^{z_i} = e^0 = 1$ for all $i$, so $S = 3$, and $q_i = 1/3$ for all $i$.
$L = -\ln(1/3) = \ln(3) \approx 1.0986$ nats.
This is the maximum possible loss for a 3-class problem (uniform prediction = maximum ignorance).
Practice 2 of 4

Why do practitioners almost always combine softmax with cross-entropy (rather than, say, MSE on the probabilities)?

Hint: Think about what makes backpropagation efficient. The gradient $q - y$ has no divisions, no Jacobian inversions. MSE can be differentiated (option d is false), and CE is not a metric (option c is false — it's not symmetric). Softmax outputs are real numbers, not integers (option b is false).
Answer: (a) The gradient $\partial L / \partial z_i = q_i - y_i$ is the key reason. It is simple to compute, numerically stable, has good gradient flow even when the model is badly wrong, and sums to zero (reflecting softmax shift-invariance).
Practice 3 of 4

Logits are $z = [1, 1]$ and the true class is $y = 0$ (0-indexed). What is $\frac{\partial L}{\partial z_0}$ for $L = -\ln q_y$ (natural log)?

Hint: Equal logits → $q_0 = q_1 = 0.5$. Use the formula $\partial L / \partial z_0 = q_0 - y_0 = 0.5 - 1$.
Solution: With $z = [1, 1]$, we get $q = [0.5, 0.5]$ (uniform over 2 classes).
$\frac{\partial L}{\partial z_0} = q_0 - y_0 = 0.5 - 1 = -0.5$.
The negative sign means "increase $z_0$" — the model should become more confident about class 0.
